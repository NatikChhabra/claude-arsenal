# advocate

Case work for an advocate in a court that publishes its own rules: moot court, mock trial, roleplay or community courts.
Everything is built from the case file and the court's own law text, never from real-world law by default.

## Skills

| Skill | What it does |
|---|---|
| `trial-prep` | A complete prep pack for first or second chair: deadlines from the judge's order, charges and elements, evidence and discovery, theory, cross banks, objections, court-day duties |
| `cell-rep` | Live, fast help at a police station or holding cell: where to go, the in-cell card (questions, rights, charges, bail and plea), and a live-answer helper kept in cell-rep mode so every rep needs zero setup |
