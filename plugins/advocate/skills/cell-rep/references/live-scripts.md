# Live scripts: station bail, bail hearing, bench trial, run sheet, argument bank

Templates for a live-answer helper (or for the advocate to read from) when a cell rep turns into bail or a bench trial.
Load the court's own text into each [bracket]: section numbers, the non-bailable list, the bail benchmark, the
objection list and the trial order all differ between courts. Never fill a bracket from memory of another court.
Every quoted line is something the advocate says out loud. Keep the order of the hearing.

## Why these exist
On the first rep that reached a bail and bench-trial offer (2026-11-09), the helper asked good questions but gave 3
short lines per moment and no plan. The advocate said he "didn't know how to use the information" and wanted lines he
could just follow. Scripts fix that: a run sheet for the whole rep, a script per hearing, and each defence point worded
for each audience.

## A. Bail at the station (no judge on duty)
1. "Officer, my client pleads Not Guilty, and he's requesting bail now."
2. "With no judge on duty, [bail section] says bail must be provided. None of his charges is on its list: [list]."
3. "The benchmark is [benchmark, e.g. the maximum accrued fine]. That's $[sum]. Set it there."
4. "Standard conditions only. [Section] bars custom conditions." (only if the code says so)
5. "So it's Not Guilty, bail at $[amount], standard conditions. Confirm that and he'll pay now."
Counters: "too serious" -> "[Section] says must, not may. Which listed charge applies?"; "flight risk / priors" ->
"Priors aren't on the list. A judge can revisit bail later; today it must be set."; "act suspended" -> "Show me the
order that suspends the bail section."; "already on bail" -> check whether the code bars officer bail only for a
rearrest for breaking bail, then ask for a judge's hearing and its deadline.
Then to the client: plea entered, amount, conditions, every court date, the deadline to declare counsel, and what
happens if the State misses its own filing deadline.

## B. Bail hearing before a judge
Order (check the court's procedure): charges read, prosecution contests, defence rebuts, judge decides.
1. Only correct a wrong charge figure while charges are read: "Your Honor, a correction: the code puts [charge] at [X]."
2. "Your Honor, the defence asks for bail at $[benchmark] with the standard conditions."
3. Reasons, one line each, only those the facts support: bail is the rule under [section]; the benchmark already
   prices in seriousness; the client came in, cooperated or asked for counsel; no failures to appear; one weak point
   in the State's case.
4. Rebut THEIR point first: danger -> "Standard conditions answer that."; flight -> a fact showing he stays;
   seriousness -> "Seriousness sets the amount, not whether bail exists."
5. "We ask for bail at $[amount], standard conditions. Thank you, Your Honor."
6. If denied: "For the record, the defence objects, and we'll petition [the next hearing the code allows]."

## C. Bench trial
Read the court's own differences from a full trial first. In the first court checked: no opening statements, the
judge may question witnesses, closings only if either side wants one (then both, State first), and an officer may
present the case when no prosecutor is available. Before choosing bench, tell the client the trade in two lines:
win = walk; lose = up to the full maximum (some courts can double it for a frivolous defence). Take a fair deal instead
when the facts are solid.
1. Before it starts: move to exclude evidence from a search without probable cause; flag any count missing an element.
2. During the State's case: "Objection, [ground]." from the court's official list only, no speaking objections.
   Map: story with no question = narrative; someone else's words = hearsay; guess = speculation; feeding answers =
   leading; unproven premise = assumes facts; didn't see it = lacks foundation.
3. Cross each witness with yes/no questions, one fact each, never "why", stop once the answer is in. Blocks: the stop,
   the order, the search, weight or count, identification, warnings, the written report ("Read me the line where you
   recorded [missing fact]. It isn't there?").
4. Defence case: usually rest. A client on the stand can be cross-examined.
5. Closing: "The State has to prove every element beyond a reasonable doubt. It hasn't. On [charge], [gap]. On
   [charge], [gap]. The defence asks for Not Guilty on every count."
6. If convicted: always give a sentencing recommendation with reasons. In one court's bench trial the State asked for
   the standard sentence, the defendant offered none, and the judge still cut it by three quarters for cooperation;
   an advocate's specific number is free leverage.

## D. Cell rep run sheet (give the NEXT stage, never restart)
1. Arriving: answer the officer's own security questions plainly ("No weapons, Officer. Here's my ID."); ask for the
   arresting officer and the charges.
2. Private with the client, in order: why the stop; what happened at the arrest; search and consent; exactly what was
   found and how much; warnings and questions before them; priors and bail. Then the plan in three lines (weak point,
   the ask, what happens if they won't move). If the client wants to plead guilty to everything: "Guilty is final.
   Give me five minutes first. You still choose."
3. Negotiate: strike, then the number, then leverage ("Then it's Not Guilty, the State's filing clock starts, and we
   ask for a bench trial.").
4. Read-back before any plea. 5. Not Guilty: say it once, ask for bail (A) or bench (C). 6. Before leaving: the client's
   deadlines and "talk to no one about this".

## E. Argument bank: each point worded for three audiences
Write each point once per audience, so the helper can pick by who is listening:
- Officer at the station: the point, the fact they admitted, the ask ("Drop [charge], or we take it to a judge today.").
- Judge: the rule, the officer's own account, the conclusion ("what followed from it shouldn't be used").
- Client: plain words, "you", what it means for him, and "say nothing more about it".
Points worth a card in most codes: no reasonable suspicion for the stop; arrest without probable cause; search without
probable cause or consent; an order "disobeyed" by words only; weight or count never measured; a more specific charge
for the item; identification on looks alone; answers before warnings; charges added after a lawyer was requested;
and a leverage close.
Say each point once at full strength, then use it as leverage. Repeating it every line reads as a loop.
