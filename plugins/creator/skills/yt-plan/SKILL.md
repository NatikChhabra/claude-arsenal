# yt-plan

status: beta

A plan that does not fit the week is a list of regrets. Use the project's own schedule if it has one (cadence, slot,
length, Shorts per long, known breaks); topics come from skill `topic-pick`, never invented here. Start from what is
already half-made (the project's hand-off or plan file).

## Before you write

1. Read the project's voice file (for example `voice.md`) if it has one, and run any public text through its
   voice checker if it has one. The project's own rules (its CLAUDE.md or equivalent) win over this generic skill, and
   nothing is posted or interacted with (comment, reply, heart, pin) without the creator's OK for that exact action.
2. Never invent a number, a result or a source. If a figure would strengthen it and you do not have
   one, ask for it or write the line without it.

## The shape of a week

- **One anchor.** The video the week is for. It gets the most time and it goes out on the day the
  channel's own analytics say is best - ask for that, do not assume Tuesday.
- **No cheap filler.** No off-format uploads on the main channel (Q&A, vlogs, channel updates ran 0.02-0.25x their
  channels' median). A second long video is a real one (a Part 2 or the next game), or nothing.
- **Shorts from the anchor.** 2-3, cut from the long video, not written separately. `/shorts`
  cuts them; Reels are the same moments cut for Instagram, posted at the audience's evening peak, the first one on the
  long's day and the rest on days without a Short.

Three uploads on a seven-day week, not seven. A plan that posts daily is not a plan anyone
recognises, and the empty days are what make the filled ones survive a bad week.

## What to hand back

A table: day, format, working title, the one sentence it promises, and what already exists for it.
Then the honest line at the bottom: what to drop first if the week goes wrong.

## The gate

The output goes into the video's package file (the upload sheet the project uses, or skill `publish-meta`); nothing is
published here. Posting or interacting needs the creator's OK for that exact action.
