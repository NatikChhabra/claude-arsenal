# Brand kit

status: draft

## Output: `brands/<name>/BRAND.md` + `brands/<name>/assets/`
1. Positioning in one line, and three personality words.
2. Palette: 1 primary, 1 accent, 2 neutrals, with hex codes and contrast-checked text pairs (WCAG AA).
3. Type: one display face, one text face (free licences: Google Fonts), sizes for poster/social/phone.
4. Logo direction: 3 concepts as SVG sketches (Claude can write SVG directly), pick one, refine.
5. Voice: how it talks in ads and posts, with 5 example lines and 5 lines it would never say.
6. Do/don't sheet. Every later design and marketing skill reads this file first.
