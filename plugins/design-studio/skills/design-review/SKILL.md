# Design review

status: draft

Render at the smallest real display size and check, 1-5 each; fix anything under 4:
- One focal point; the eye path goes focal -> headline -> action.
- Text readable at phone size (and at in-game billboard distance when relevant); spelling exact.
- Brand fit: palette, type and voice match BRAND.md.
- No AI tells: garbled text, extra fingers, plastic skin, generic gradients, stock phrasing.
- Contrast passes WCAG AA for text.
- Different from the last three designs for the same brand (no template feel).
