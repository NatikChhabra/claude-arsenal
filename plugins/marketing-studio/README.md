# marketing-studio

Campaign plans, release rollouts and per-platform copy in the brand's own voice.

Skills: `campaign-plan` (writes `marketing/<slug>/PLAN.md`), `release-rollout`, `social-copy`. Each reads the brand kit
(`brands/<name>/BRAND.md`, from the `design` skill, references/systems.md) first. Nothing posts without the owner's OK
for that post. All skills are `status: draft` until used on a real launch.

## Install

```
/plugin install marketing-studio --marketplace NatikChhabra/claude-arsenal
```
