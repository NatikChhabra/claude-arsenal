# Release rollout

status: draft

## Checklist
- Assets: master audio, cover art (3000x3000), 16:9 video, 9:16 cut-downs (3+ hooks from different song moments),
  lyrics, credits.
- Distribution choice for streaming (DistroKid, TuneCore, etc.) after checking the vocal tool's licence allows it.
- Metadata: title, artist name, genre, language, ISRC if distributed, AI-use disclosure where the platform requires it.
- Teasers 3-7 days before; launch-day posts per platform (each written for that platform); RP in-world premiere if allowed.
- Nothing posts publicly without the owner's explicit OK for that post.
- Follow-up at +2 days and +7 days: numbers into the plan, one change for the next release.
