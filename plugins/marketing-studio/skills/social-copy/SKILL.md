# Social copy

status: draft

## Rules
- Read the brand's voice first (`brands/<name>/BRAND.md`, the brand kit from skill design, references/systems.md). Write like the character or business would talk, specific to this moment.
- Per platform: Instagram (first line carries it), TikTok/Shorts (hook in on-screen text + first 2 s), Discord (clear
  what/when/where), in-game ads (short, server's ad format and rules).
- Banned: em dashes, "unleash", "elevate", "game-changer", "dive in", "you won't believe", emoji walls, hashtag walls.
- Give 3 options with different angles; say which one you'd pick and why.
