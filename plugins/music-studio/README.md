# music-studio

Songwriting, vocals for a guitarist who can't sing, guitar capture, production, mixing, mastering and music videos.

Start with skill `song-from-idea`; it ends in a song sheet (`songs/<slug>/SONG.md`) the other skills build on:
`vocal-route`, `guitar-capture`, `produce-arrange`, `mix-master`, `music-video`, and `music-review` before delivery.
Tools and their verdicts: [registry/tools.md](../../registry/tools.md); vocal routes researched in
[research/01_vocals_for_non_singers.md](../../research/01_vocals_for_non_singers.md). Picture and motion rules for
music videos and covers: the `design` plugin. All skills are `status: draft` until used on a real song.

## Install

```
/plugin install music-studio --marketplace NatikChhabra/claude-arsenal
```
