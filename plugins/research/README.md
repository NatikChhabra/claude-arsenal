# research

Take a finished research paper public and into circulation, honestly.

Skills:
- `paper-release`: a citable public preprint and up-to-date researcher profiles (Zenodo DOIs, ORCID, Google Scholar,
  LinkedIn, arXiv), with the pitfalls of each.
- `research-outreach`: emails to researchers, conference chairs and news desks that get read, and what to expect back.
- `author-ownership`: when an AI agent ran much of the study, build the human author's own understanding and a
  written contribution that venues will accept.

Nothing is sent, posted or submitted without the owner's OK for that item. Every number in a paper comes from code
that was run; every citation is checked against its source. Visual rules (posters, figures, slides) live in the
`design` plugin.

## Install

```
/plugin install research@claude-arsenal
```
